## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed locally:
- Git
- Modern Web Browser


### Installation

```bash
# Clone repository
git clone https://github.com/RishabhRaj240/html-landing-showcase.git
cd html-landing-showcase
```

### Running the Application

```bash
# Open index.html directly in any browser:
open index.html      # On macOS
start index.html     # On Windows
xdg-open index.html  # On Linux

# Or serve with a local static web server:
npx serve .
```
